# Typing Race

## Product
Real-time multiplayer typing race.

## Core rules
- No login
- No profile
- Maximum 6 players
- Players can create or join a party
- Party uses 4-digit code
- Party also has shareable invite URL
- Random username on entry
- Username can be edited
- Race can start with fewer than 6 players
- Same text for all players
- Winner determined by typing progress/time
- Temporary rooms only
- No database in v1

## Tech stack
