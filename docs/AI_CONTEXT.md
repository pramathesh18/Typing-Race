# AI DEVELOPMENT CONTEXT

Before modifying the project:

1. Read PROJECT.md
2. Read STATE.md
3. Read TODO.md
4. Read relevant specification files
5. Inspect existing code before creating new code

Rules:

- Preserve existing naming.
- Do not rewrite working components unnecessarily.
- Do not invent APIs.
- Do not change the tech stack without explicit instruction.
- Do not add dependencies without checking whether they are necessary.
- Do not duplicate functionality.
- Follow existing folder structure.
- Update project documentation after meaningful architectural changes.

When a task is given:
- Determine which phase it belongs to.
- Inspect relevant existing code.
- Implement the smallest complete change.
- Test the change.
- Update STATE.md.
- Update TODO.md.
